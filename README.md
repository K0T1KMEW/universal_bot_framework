# Universal Bot Framework

A unified framework for creating bots across multiple platforms.

## Features

- **Unified API**: Write once, deploy to multiple platforms
- **Cross-platform**: Support for Telegram, VK, Discord (more coming soon)
- **Easy to use**: Simple decorator-based syntax
- **Middleware support**: Pre- and post-processing middleware
- **Flexible filters**: Powerful filtering system for handlers

## Installation

```bash
pip install universal-bot-framework
